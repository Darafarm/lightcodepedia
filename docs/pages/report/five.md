## Collecting Information from Visitors

Do you want to collect the same type of information from a variety of users of your platform and you're confused on how to go about it? 

**Forms** come to the rescue in times like this as they collect structured information from users especially during login and registration points.


However, **standard Markdown cannot create forms by itself**. Instead, many websites and documentation platforms extend Markdown by allowing forms to be described using **YAML** or **JSON**.

# YAML vs JSON

Both formats describe the same information. Choose the format required by the platform you are using.


| YAML | JSON |
|-------|------|
| Easy for humans to read | Easy for computers to process |
| Uses indentation | Uses braces and brackets |
| Less punctuation | More punctuation |
| Common in configuration files | Common in APIs and web applications |

# Best Practices

✅ Use meaningful labels.

✅ Use the correct field type.

✅ Keep forms simple.

✅ Check your indentation in YAML.
